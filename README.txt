나의 이력서 웹사이트
====================

파일 구성
- index.html : 웹사이트 내용과 구조
- style.css  : 색상, 레이아웃, 글꼴, 모바일 화면 스타일
- script.js  : 모바일 메뉴, 스크롤 효과, 이메일 복사 등 동작

실행 방법
1. 세 파일을 같은 폴더에 둡니다.
2. index.html 파일을 Chrome, Edge 등 브라우저에서 엽니다.

수정할 때 참고하세요
- 이름, 소개 문장, 경력, 프로젝트, 학력 등은 index.html에서 수정합니다.
- 색상, 글자 크기, 간격, 모바일 화면 디자인은 style.css에서 수정합니다.
- 버튼 동작 등은 script.js에서 수정합니다.
- 이메일 주소는 index.html에서 your.email@example.com으로 검색해 본인의 주소로 바꾸세요.
- 현재 경력과 기술 정보는 웹사이트 초안을 보여 주기 위한 예시/자리표시자입니다. 실제 이력에 맞게 바꿔 주세요.

참고
- 일부 글꼴은 인터넷 연결 시 Google Fonts에서 불러옵니다. 인터넷이 없어도 기본 글꼴로 표시됩니다.
